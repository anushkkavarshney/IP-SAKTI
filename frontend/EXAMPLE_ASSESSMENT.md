# Example Assessment — IP-SAKTI Navigator

## Paste this description into the Innovation Input field

A standardized, ethanol-based root extract of Withania somnifera (Ashwagandha)
delivered in a modified-release capsule, intended as a therapeutic formulation for
stress and anxiety. The extraction process uses a novel, temperature-controlled
fractionation method to concentrate withanolides. The botanical source is
cultivated in Rajasthan, India. The primary target market is India.

## Clarification answers to select

| Question | Select |
|---|---|
| 1. What is the primary intended use and form of your product? | Therapeutic / Medicinal Treatment (Internal Consumption) |
| 2. Is this product based on an authoritative classical Ayurvedic text? | Classical herb(s) utilized, but with a modified formulation or novel process |
| 3. Does the innovation involve a new extraction method, delivery mechanism, or process? | Yes, novel extraction technique, nanocarrier, or specialized processing method |
| 4. Does your innovation use biological resources harvested or sourced within India? | Yes, Indian medicinal plants/herbs (wild or cultivated) |
| 5. What is the target jurisdiction for regulatory filing and commercialization? | India (Primary Jurisdiction) |

If you select the **Ashwagandha** preset in the Innovation Input step, these
answers are auto-filled.

## Expected output when the backend is running

The analysis should return the following summary (mirrors the built-in sample
response):

- **Classification:** Proprietary Ayurvedic Medicine
- **Confidence:** 87 (HIGH)
- **IP analysis:** Process patent potential; Section 3(p) traditional knowledge
  scrutiny; Section 3(e) mere admixture scrutiny; NBA Form III approval required.
- **ABS (biodiversity):** Applicable. Resource: Withania somnifera. Action items:
  Form III to NBA before filing; Section 7 SBB intimation if sourcing from
  Indian states; benefit-sharing agreements per NBA ABS Guidelines.
- **Regulatory:** AYUSH / Proprietary Ayurvedic Medicine (ASU Drug). Key steps:
  botanical authentication, safety/efficacy data under Rule 158B, GMP
  manufacturing license (Form 24D / Schedule T), Rule 161 labelling.
- **Verification:** 4 claims evaluated; 3 supported, 1 partially supported.
- **Evidence:** References Patents Act 1970 (Sections 3(p), 3(e), 2(1)(j)),
  Biological Diversity Act 2002 (Sections 6(1), 7), Drugs & Cosmetics Rules
  1945 (Rule 158B, Schedule T).

## What happens if the backend is not running

The frontend will display an error state. Choose **Use Sample Data** to view the
same response described above; it will be clearly marked as illustrative sample
data.
